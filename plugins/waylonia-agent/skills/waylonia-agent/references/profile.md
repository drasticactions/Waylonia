# The agent profile

The plugin's server runs the profile `claude`. Its files are under
`$XDG_STATE_HOME/waylonia/agents/claude/`, which is `~/.local/state/waylonia/agents/claude/` by
default:

| Path | What it holds |
| --- | --- |
| `agent.toml` | The policy. Written as a commented placeholder on the first run. |
| `home/` | `HOME` and the `XDG_*_HOME` directories of every launched application. |
| `logs/` | One log per launch, stdout and stderr. `process_log` reads it. |
| `audit/` | One JSON Lines file per run: every call, its result and the approvals. |

`agent.toml` is read once, when the server starts. After the user edits it, the server must be
restarted: `/mcp`, then reconnect `plugin:waylonia-agent:waylonia`.

You tell the user what to change. You do not edit this file.

## Launches

`waylonia_launch` starts any program at once: a `command` (with `args`) on `PATH` or by path, or an
installed application by `desktop_id`. There is no allowlist. To have a person approve each launch,
add `launch` to `[approve] actions`:

```toml
[approve]
actions = ["launch"]
```

A `[launch]` table from an older profile is ignored with a warning.

## Other keys

| Key | Values | Default |
| --- | --- | --- |
| `size` | `"WxH"` | `"1280x800"` |
| `scale` | 0.5 to 4 | `1.0` |
| `headless` | `true`, `false` | `false` (the plugin passes `--headless`) |
| `placement` | `"maximize"`, `"automatic"` | `"maximize"` |
| `takeover-timeout` | seconds, 0 to 3600 | `10` |
| `keymap` | an xkb layout | `"us"` |
| `[approve] actions` | `launch`, `clipboard-read`, `clipboard-write`, `close-window`, `kill` | none |
| `[audit] screenshots` | `"none"`, `"acting"`, `"all"` | `"acting"` |
| `[audit] text` | `true` logs typed text, `false` logs its length and SHA-256 | `false` |
| `[accessibility] enabled` | `true`, `false` | `true` |
